# Talycap

Solución de las pruebas técnicas de backend, frontend y base de datos.

- [Backend .NET 6](backend-dotnet6/README.md): consulta de clientes con SQL Server, EF Core y Swagger.
- [Frontend Angular 21](frontend-angular21/README.md): tablas de clima y series, filtros, paginación y pruebas unitarias.
- [SQL Server](database-sqlserver/README.md): modelo de empleados y proyectos, consultas y consumo de API.

Cada carpeta tiene las instrucciones para instalar, ejecutar y probar su proyecto.
El backend usa `DBClientes`; el ejercicio de SQL usa `EmpresaDB`. El frontend consulta APIs públicas y se ejecuta de forma independiente.
